เพิ่มเพลงใหม่

1. วางไฟล์ MP3 ที่ได้รับอนุญาตให้เผยแพร่ไว้ในโฟลเดอร์นี้ และตรวจว่าแท็ก ID3 ของแต่ละไฟล์มีชื่อเพลงที่ถูกต้อง
2. เปิด PowerShell ที่โฟลเดอร์เว็บไซต์ แล้วรัน:
   python build_music_playlist.py
3. เผยแพร่เว็บไซต์พร้อมไฟล์ MP3 และ playlist.json ที่อัปเดตแล้ว

ตัวสร้างรายการจะอ่านชื่อจากแท็ก ID3 ไม่ได้อาศัยชื่อไฟล์อย่างเดียว และจะหยุดพร้อมแจ้งเมื่อชื่อในแท็กไม่ตรงกับเพลงประจำที่ตั้งไว้
