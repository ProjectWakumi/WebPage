# WebWakumi

Static site for GitHub Pages: <https://ysdwakumi.github.io/WebWakumi/>.

Pushing to `main` deploys the repository root through GitHub Actions. The workflow attempts to enable GitHub Pages automatically; if repository permissions prevent that, select **GitHub Actions** as the build and deployment source in **Settings → Pages**.

Audio files are intentionally not included in the published site. Add only audio that is licensed for redistribution, then update `assets/music/playlist.json`.
